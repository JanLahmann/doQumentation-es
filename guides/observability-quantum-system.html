Eventos de seguimiento de actividad para el servicio IBM Quantum System

Los servicios de IBM Cloud®, como el servicio IBM® Quantum System, generan eventos de seguimiento de actividad.

Los eventos de seguimiento de actividad informan sobre las actividades que cambian el estado de un servicio en IBM Cloud. Puedes usar los eventos para investigar actividades anómalas y acciones críticas, y para cumplir con los requisitos de auditoría regulatoria.

Puedes usar IBM Cloud Activity Tracker Event Routing, un servicio de plataforma, para enrutar eventos de auditoría en tu cuenta hacia los destinos que elijas configurando destinos y rutas que definen hacia dónde se envían los eventos de seguimiento de actividad. Para más información, consulta About IBM Cloud Activity Tracker Events Routing.

Puedes usar IBM Cloud Logs para visualizar y generar alertas sobre eventos generados en tu cuenta y enrutados por IBM Cloud Activity Tracker Event Routing hacia una instancia de IBM Cloud Logs.

Ver eventos de seguimiento de actividad para el servicio IBM Quantum System​

Puedes usar IBM Cloud Logs para visualizar y generar alertas sobre eventos generados en tu cuenta y enrutados por IBM Cloud Activity Tracker Event Routing hacia una instancia de IBM Cloud Logs.

Iniciar IBM Cloud Logs desde la página de Observabilidad​
