Descripción del algoritmo de Grover

En esta sección describimos el algoritmo de Grover. Comenzamos con la discusión de las puertas de consulta de fase y cómo construirlas, seguida de la descripción del algoritmo en sí. Finalmente, discutimos brevemente cómo el algoritmo se aplica naturalmente a la búsqueda.

Puertas de consulta de fase​

El algoritmo de Grover utiliza operaciones conocidas como puertas de consulta de fase. A diferencia de una puerta de consulta ordinaria UfU_fUf​, que para una función dada fff se define como se describió anteriormente, una puerta de consulta de fase para la función fff se define de la siguiente manera:

Zf∣x⟩=(−1)f(x)∣x⟩Z_f \vert x\rangle = (-1)^{f(x)} \vert x\rangleZf​∣x⟩=(−1)f(x)∣x⟩

para cada cadena x∈Σnx\in\Sigma^nx∈Σn.

Esta implementación aprovecha el fenómeno de retroceso de fase y requiere que un qubit auxiliar, inicializado en el estado ∣−⟩\vert -\rangle∣−⟩, esté disponible. Este qubit permanece en el estado ∣−⟩\vert - \rangle∣−⟩ después de la implementación y puede reutilizarse (por ejemplo, para implementar puertas ZfZ_fZf​ posteriores) o simplemente descartarse.

Además de la operación ZfZ_fZf​, también usamos una puerta de consulta de fase para la función OR de nnn bits, que se define para cada cadena x∈Σnx\in\Sigma^nx∈Σn de la siguiente manera:

OR(x)={0x=0n1x≠0n\mathrm{OR}(x) = \begin{cases} 0 & x = 0^n\\[0.5mm] 1 & x \neq 0^n \end{cases}OR(x)={01​x=0nx=0n​

Explícitamente, la puerta de consulta de fase para la función OR de nnn bits actúa así:

ZOR∣x⟩={∣x⟩x=0n−∣x⟩x≠0n.Z_{\mathrm{OR}} \vert x\rangle = \begin{cases} \vert x\rangle & x = 0^n \\[0.5mm] - \vert x\rangle & x \neq 0^n. \end{cases}ZOR​∣x⟩={∣x⟩−∣x⟩​x=0nx=0n.​

Para ser claros: así es como ZORZ_{\mathrm{OR}}ZOR​ actúa sobre estados de la base estándar; su comportamiento para estados arbitrarios se obtiene por linealidad a partir de esta expresión.

La operación ZORZ_{\mathrm{OR}}ZOR​ puede implementarse como un circuito cuántico comenzando con un circuito booleano para la función OR, convirtiéndolo en una operación UORU_{\mathrm{OR}}UOR​ (es decir, una puerta de consulta estándar para la función OR de nnn bits) — según el procedimiento descrito en la lección Fundamentos algorítmicos de la computación cuántica —, y finalmente construyendo una operación ZORZ_{\mathrm{OR}}ZOR​ mediante el fenómeno de retroceso de fase. Observa que ZORZ_{\mathrm{OR}}ZOR​ no tiene dependencia de la función fff y, por lo tanto, puede implementarse mediante un circuito cuántico sin puertas de consulta.

Descripción del algoritmo​

Ahora que tenemos las dos operaciones ZfZ_fZf​ y ZORZ_{\mathrm{OR}}ZOR​, podemos describir el algoritmo de Grover.

El algoritmo se refiere a un número ttt, que indica el número de iteraciones (y por tanto el número de consultas a la función fff). Este número ttt no está determinado por el algoritmo de Grover en la forma aquí descrita; discutiremos más adelante en la lección cómo puede elegirse.

Algoritmo de Grover
  1. Inicializar un registro de nnn qubits Q\mathsf{Q}Q en el estado cero ∣0n⟩\vert 0^n \rangle∣0n⟩ y luego aplicar una operación de Hadamard a cada qubit de Q\mathsf{Q}Q.
  2. Aplicar ttt veces la operación unitaria G=H⊗nZORH⊗nZfG = H^{\otimes n} Z_{\mathrm{OR}} H^{\otimes n} Z_fG=H⊗nZOR​H⊗nZf​ al registro Q\mathsf{Q}Q.
  3. Medir los qubits de Q\mathsf{Q}Q en la base estándar y devolver la cadena resultante.

La operación G=H⊗nZORH⊗nZfG = H^{\otimes n} Z_{\mathrm{OR}} H^{\otimes n} Z_fG=H⊗nZOR​H⊗nZf​ iterada en el paso 2 se denominará la operación de Grover en el resto de esta lección. Aquí hay una representación en circuito cuántico de la operación de Grover para n=7 ⁣:n=7\!:n=7:

En este diagrama, la operación ZfZ_fZf​ se muestra más grande que ZORZ_{\mathrm{OR}}ZOR​ — una indicación visual informal de que probablemente es la operación más costosa. En particular, ZfZ_fZf​ requiere una consulta en el modelo de consulta, mientras que ZORZ_{\mathrm{OR}}ZOR​ no requiere consultas. Si, en cambio, tenemos un circuito booleano para la función fff y lo convertimos en un circuito cuántico para ZfZ_fZf​, puede suponerse que el circuito cuántico resultante será más grande y complejo que uno para ZORZ_{\mathrm{OR}}ZOR​.

Aplicación a la búsqueda​

El algoritmo de Grover puede aplicarse al problema de búsqueda de la siguiente manera:

  • Elegir el número ttt en el paso 2. (Esto se discutirá más adelante en la lección.)
  • Ejecutar el algoritmo de Grover para la función fff con el número ttt elegido, para obtener una cadena x∈Σnx\in\Sigma^nx∈Σn.
  • Consultar la función fff para la cadena xxx para verificar si es una solución válida:
    • Si f(x)=1,f(x) = 1,f(x)=1, hemos encontrado una solución y podemos detenernos y devolver xxx.
    • Si f(x)=0,f(x) = 0,f(x)=0, podemos ejecutar el procedimiento de nuevo, posiblemente con una elección diferente para ttt, o podemos rendirnos y devolver "sin solución".

Una vez que hayamos analizado cómo funciona el algoritmo de Grover, veremos que eligiendo t=O(N)t = O(\sqrt{N})t=O(N​) obtenemos una solución a nuestro problema de búsqueda con alta probabilidad (siempre que exista una).
