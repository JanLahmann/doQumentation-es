Funciones

doQumentation convierte el contenido de código abierto de IBM Quantum en una plataforma de aprendizaje interactiva con ejecución de código en vivo, modo simulador y seguimiento del progreso de aprendizaje.

381 Páginas de Contenido

42 Tutoriales, 171 Guías, 154 páginas de Cursos y 14 Módulos — todo procedente de la documentación de código abierto de Qiskit de IBM Quantum.

Explorar tutoriales →

Auto-Sincronización desde Upstream

El contenido se sincroniza automáticamente desde el repositorio de GitHub de IBM, manteniendo los tutoriales y cursos actualizados con las últimas versiones de Qiskit. Last upstream content update: 2026-06-02 (commit c0c4e18).

Navegación Estructurada

Barras laterales generadas automáticamente con categorías plegables. Los Tutoriales, Guías, Cursos y Módulos tienen cada uno su propia barra lateral organizada.

Ejecución de Código en Vivo

Alternancia Ejecutar / Volver

Cada página de notebook tiene un botón Ejecutar que activa todas las celdas de código con un kernel de Jupyter en vivo. Haga clic en Volver para regresar a la vista estática.

Tres Backends de Ejecución

Ejecución remota gratuita a través de Binder (sin instalación necesaria), completamente offline a través de Docker, o autoalojado en un RasQberry Pi.

Configurar backend →

IBM Cloud Code Engine

Kernel Jupyter sin servidor en tu cuenta de IBM Cloud. Inicio en frío en segundos en lugar de los 10–25 minutos de Binder. El nivel gratuito cubre aproximadamente 14 horas al mes.

Configurar Code Engine →

Modo Workshop

Realiza talleres con hasta 50 participantes. Despliega múltiples instancias de Code Engine y comparte una única URL — los participantes se distribuyen automáticamente con sesiones fijas y failover automático.

Guía de configuración del workshop →

Monitoreo de Workshop

Panel en vivo con actualización automática (30 s) que muestra recuentos de kernels por instancia, kernels activos, conexiones, uso de memoria y tiempo de actividad. Cada instancia expone un endpoint /stats. El script de prueba de carga simula usuarios concurrentes para encontrar los límites de capacidad antes de que comience la clase.

Panel de Configuración →

Abrir en Google Colab

Cada página de notebook tiene un botón 'Abrir en Colab' para ejecución en la nube sin instalación. Abre notebooks traducidos al navegar en otro idioma.

Retroalimentación de Ejecución de Celdas

Retroalimentación visual en cada celda: borde ámbar mientras se ejecuta, verde al terminar, rojo en caso de error. Aparece una leyenda en la barra de herramientas cuando el kernel está listo.

Sugerencias de Error Contextuales

Detección automática de ModuleNotFoundError, NameError y desconexión del kernel. Aparecen sugerencias accionables debajo de la celda con correcciones sugeridas.

Instalación pip con Un Clic

Cuando se detecta un paquete faltante, aparece un botón 'Instalar' en el que se puede hacer clic. Después de completar la instalación, la celda fallida se vuelve a ejecutar automáticamente.

Abrir en JupyterLab

Cada página de notebook tiene un botón para abrir el .ipynb completo en JupyterLab para edición avanzada y exploración.

Ejecutar todo y reiniciar

Ejecutar todo ejecuta cada celda en orden con un contador de progreso en vivo. Detente después de la celda actual en cualquier momento. Reiniciar te da un kernel nuevo sin perder tu sesión de Binder.

Integración con IBM Quantum

Almacenamiento de Credenciales

Guarde su token de API de IBM Quantum y CRN una vez en Configuración. Almacenado localmente en su navegador con caducidad automática de 7 días por seguridad.

Configurar credenciales →

Auto-Inyección

Las credenciales se inyectan silenciosamente en el kernel al iniciar. No es necesario pegar tokens en cada notebook — solo haga clic en Ejecutar.

Modo Simulador

Ejecute todos los notebooks sin una cuenta de IBM Quantum. Elija AerSimulator para simulación ideal, o elija entre docenas de FakeBackends que modelan el ruido de dispositivos reales. No requiere configuración.

Activar simulador →

Insignia de Modo de Ejecución

La barra de herramientas muestra qué modo está activo — el nombre del simulador (p. ej., 'FakeSherbrooke') o 'IBM Quantum' — para que siempre sepa cómo se está ejecutando su código.

Aprendizaje y Progreso

Seguimiento del Progreso

Las páginas que visita obtienen una marca de verificación (✓) en la barra lateral. Los notebooks que ejecuta obtienen un indicador de reproducción (▶). Siga su recorrido a través del contenido.

Insignias de Categoría

Cada categoría de la barra lateral muestra una insignia como '3/10' para que pueda ver el progreso de un vistazo. Haga clic para borrar el progreso por sección.

Reanudar Lectura

La página de inicio muestra una tarjeta 'Continuar donde lo dejó' con su última página visitada y cuándo estuvo allí.

Ir a la página de inicio →

Marcadores

Marca cualquier página con una estrella para añadirla a marcadores. Los marcadores aparecen en la página de inicio. Almacenados localmente, hasta 50 páginas.

Ver marcadores →

Páginas recientes

La página de inicio muestra tus 5 páginas visitadas más recientemente para acceso rápido.

Ir a la página de inicio →

Preferencias de Visualización

Ajusta el tamaño de fuente del código (10–22 px), activa/desactiva las salidas estáticas de celdas y suprime las advertencias de Python para una salida más limpia.

Ajustar visualización →

Consejos de incorporación

Los visitantes por primera vez ven consejos contextuales — como "Haz clic en Ejecutar para ejecutar código en vivo" en páginas de notebooks. Los consejos se descartan automáticamente después de unas visitas.

Multiidioma

20 Idiomas

El sitio completo está disponible en 20 idiomas, incluyendo alemán, japonés, español, francés y más. Cada idioma funciona en su propio subdominio con interfaz traducida.

Respaldo automático

Las páginas no traducidas vuelven al inglés con un banner en el idioma del lector, para que ninguna página falte nunca.

Búsqueda, UI y Despliegue

Búsqueda Local

Búsqueda de texto completo en todas las 381 páginas, funciona sin conexión. Los resultados aparecen instantáneamente mientras escribe.

Modo Oscuro

Soporte completo para tema oscuro. Los diagramas de circuitos y las salidas de Matplotlib se invierten automáticamente para mayor legibilidad.

Incrustaciones de Video

Videos de cursos con mapeo a YouTube para reproducción confiable. Recurre a IBM Video cuando YouTube no está disponible.

Despliegue con Docker

Construcción de Docker de múltiples etapas con CI/CD a GitHub Container Registry. Pila completa (sitio + Jupyter) o imagen estática ligera.

Diseño Responsivo

Navegación tipo hamburguesa, desplazamiento horizontal de código y cuadrículas de tarjetas responsivas. Funciona en teléfonos y tabletas.

Renderizado Matemático

KaTeX para renderizado de matemáticas LaTeX rápido y de alta calidad en todas las páginas de contenido — ecuaciones, matrices y notación cuántica.
